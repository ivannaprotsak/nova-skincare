# NOVA — organic skincare

Перший екран сайту NOVA (засоби для чутливої шкіри) з інтро-анімацією: макрокадр піпетки з краплею олії → віддалення камери → пляшечка на камені → поява заголовка й решти екрана.

Статичний сайт без збірки: `index.html`, `intro.js`, `assets/`.

## Запуск локально

```bash
npx serve .
```

## Деплой

Проєкт підключений до Vercel: кожен push у `main` автоматично публікує сайт.
