# NOVA — organic skincare

Перший екран сайту NOVA (засоби для чутливої шкіри). Інтро: склад звичайного крему з 38 інгредієнтів скорочується до трьох, які лишає NOVA, після чого з'являється перший екран.

Статичний сайт без збірки: `index.html`, `intro.js`, `assets/`.

## Запуск локально

```bash
npx serve .
```

## Деплой

Проєкт підключений до Vercel: кожен push у `main` автоматично публікує сайт.
